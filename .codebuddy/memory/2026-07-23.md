## fix：分析后无工具调用结束——任务续跑处理 pending + 强调行动
- 根因：agent 思考分析后仅输出文本就 end_turn（无工具调用），loop 因 `toolUses.length===0` 中断。而任务续跑之前只查 `in_progress` 状态的任务——agent 从未标记任务为 in_progress（一直 pending），所以续跑不触发，任务永远卡在分析阶段。
- 修复：
  - `tryGetInProgressTask` → `tryGetUnfinishedTask`：先查 in_progress，若无则查 pending。
  - `TASK_CONTINUE_NUDGE` 根据 status 不同措辞：pending → 先 TaskUpdate 标记 in_progress 再调工具；in_progress → 继续执行。
  - `prompts.ts` 输出效率段新增：禁止分析后无工具调用就结束；分析后必须有行动。
