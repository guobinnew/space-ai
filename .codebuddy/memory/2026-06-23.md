# 2026-06-23 工作日志

## 通用设置统一存储到 ~/.spaceai/settings.json
- **背景**: 原通用设置(theme/locale/defaultWorkDir/notifyOnCompletion)散落在 localStorage，与 provider env(已存 settings.json) 不统一
- **改动**:
  - 服务端新增 `server/agent/services/settingService.ts` — read-modify-write 模式，与 providerService 共用 settings.json，只更新通用字段不覆盖 env
  - 服务端新增 `server/agent/api/settings.ts` — `GET/PUT /api/settings`，字段类型校验
  - `router.ts` 注册 settings 路由
  - 前端新增 `desktop/src/api/settings.ts` 客户端
  - `uiStore.tsx` 移除 localStorage，挂载时异步从服务端加载，setter 局部更新持久化(失败静默)
  - `chatStore.tsx` 的 `maybeNotifyCompletion` 改为接收 enabled 参数，由 ChatProvider 通过 `useUIStore()` 获取 notifyOnCompletion 传入，加入 useCallback 依赖
- **settings.json 结构**: `{ theme, locale, defaultWorkDir, notifyOnCompletion, env: {SPACEAI_BASE_URL, ...} }`
- **构建**: tsc + vite build 通过
