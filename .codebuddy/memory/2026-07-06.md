## 切换 tab 不断开会话 WS，仅关闭 tab 时断开
- **背景**: 原 ContentRouter 只渲染激活 tab，切换 tab 时非激活的 ActiveSession 卸载 → cleanup 断开 WS，导致切回需重连
- **改动**:
  - `ContentRouter.tsx`: 保持所有 session tab 常驻挂载，通过 `display: flex/none` 控制显隐；非 session 页面(home/settings/empty)仅激活时渲染
  - `ActiveSession.tsx`: `handleClose` 简化为仅 `closeTab`，WS 断开统一由组件卸载 cleanup 处理（避免与 cleanup 重复调用）
- **行为**:
  - 切换 tab：session 组件不卸载，WS 保持连接 ✓
  - 关闭 tab：组件卸载 → cleanup `disconnectSession` 断开 WS ✓
  - StrictMode guard `isConnectedRef` 不受影响（切换 tab 不触发 mount/unmount）
- **布局**: ContentRouter 根 `flex-1 flex flex-col`，session 包裹层 `flex-1 flex flex-col` + display 控制；所有页面根元素均有 flex-1，撑满正常
- **wsManager.disconnect/disconnectDelayed 幂等**，重复调用安全
- **commit**: 6706795
