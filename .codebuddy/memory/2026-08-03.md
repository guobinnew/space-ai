## Session 会话存储重构（commit 8a82325）

旧：`~/.spaceai/sessions/<id>.jsonl` 单文件存储所有消息。
新：`~/.spaceai/sessions/<id>/` 目录结构：
- `manifest.json`: 元信息含 `compactedThroughDate`（YYYY-MM-DD 或 null）
- `memory.md`: 压缩摘要（触发压缩后生成/更新）
- `<YYYY-MM-DD>.jsonl`: 按天分文件保存原始消息

**关键变更**：

服务端：
- `sessionService.ts` 完全重写：新 CRUD + 按天读写 + manifest + memory.md。新增 `getMessagesByDay`、`readMemory/writeMemory`、`listDays`。`getMessages`（用于 LLM 上下文）改为先读 memory.md 作为开头 user summary，再读 compactedThroughDate 之后所有 jsonl。
- `compactService.ts` 新增 `compactByDays(sessionId, callCompact, onChunk)`：把 compactedThroughDate 之后除最新一天外的所有天送 LLM 压缩，旧 memory.md + 新增内容 → 重新总结 → 写回 memory.md。**原始 jsonl 保留不删除**。补回 `isPromptTooLongError`、`DEFAULT_CONTEXT_WINDOW_*` 常量。
- `llmStreamService.ts` 在 `streamChat` 入口触发 compactByDays，压缩后重读 history。
- `api/sessions.ts` 新增 `GET /api/sessions/:id/messages?date=YYYY-MM-DD` 按天分页端点。

桌面端：
- `api/sessions.ts`: 新增 `getMessagesByDay` 客户端封装
- `types/chat.ts`: `PerSessionChatState` 增加 `loadedDays`（全部可见天列表）、`loadedDaySet`（已加载天集合）、`hasMoreHistory`、`loadingHistory`
- `chatStore.tsx`: `loadHistory` 改为加载最新一天；新增 `loadOlderDay` 加载前一天并 prepend
- `ActiveSession.tsx`: 监听滚动到顶（scrollTop<50）触发 loadOlderDay，prepend 后通过保存旧 scrollHeight 调整 scrollTop 保持视觉位置

兼容：旧 `<id>.jsonl` 在首次访问时通过 `migrateLegacyIfNeeded` 切分到对应日期 jsonl + 写 manifest + 删除原文件。index.json 全局索引保留兼容。
