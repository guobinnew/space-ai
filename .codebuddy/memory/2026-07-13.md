## 端口冲突自动重试与回退机制

问题：服务端 sidecar 异常退出后，Windows TCP 栈不立即释放端口 3721（僵尸 socket），导致重启时 EADDRINUSE。

解决方案：
- **服务端** (`server/agent/server.ts`): `startServer` 改为 async，新增 `serveWithRetry` 函数
  - EADDRINUSE 时先健康检查端口：若已有可用服务则优雅退出（exit 0）
  - 僵尸 socket 则重试 5 次（1s 间隔），仍失败则回退到 3722-3725
  - 实际端口写入 `~/.spaceai/server.port`
  - `gracefulShutdown` 时清理端口文件
- **Rust** (`lib.rs`): `get_server_port` 命令改为读取 `~/.spaceai/server.port`（回退 3721）；启动 sidecar 前清理旧端口文件
- **前端**: 新增 `desktop/src/api/serverPort.ts` 集中管理端口发现
  - `getServerPort()` 异步调 Tauri 命令，带缓存
  - `refreshServerPort()` 清缓存重读（健康检查失败时用）
  - `getCachedServerPort()` / `getCachedServerBaseUrl()` 同步访问缓存
  - `client.ts` / `tasks.ts` / `chatStore.tsx` / `HomePage.tsx` / `websocket.ts` 全部改用动态端口
