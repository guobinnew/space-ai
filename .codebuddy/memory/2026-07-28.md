## 计算机操作界面复刻 + 授权应用功能
- 复刻 smart-code 的 ComputerUseSettings 界面，增加授权应用管理功能
- **win_helper.py**: 新增 `list_installed_apps` action，支持两种输入格式（JSON 字符串 / 纯命令字符串），从 Windows 注册表（HKLM/HKCU Uninstall）读取已安装应用
- **computerUseService.ts**: 重构 `getStatus()` 返回详细结构（python/venv/dependencies/permissions），`runSetup()` 返回步骤化结果（SetupStep[]），新增 `listInstalledApps()`、`loadConfig()`/`saveConfig()`（存储到 `~/.spaceai/computer-use-config.json`）、`openSystemSettings()`

- **features.ts**: 扩展类型（ComputerUseStatus 新结构、SetupStep、InstalledApp、AuthorizedApp、ComputerUseConfig），API 方法改名 `status()`→`getStatus()`、`setup()`→`runSetup()`
- **ComputerUseSettings.tsx**: 完全重写——状态检测卡片（StatusRow/StatusIcon）、步骤化安装结果、授权应用列表（搜索+自动保存+排序）、Grant Flags 开关（剪贴板/系统快捷键）。使用内联 SVG 图标替代 smart-code 的 material-symbols
- **i18n**: 新增 30+ 翻译 key（中英文）

- **修复**：`listInstalledApps()` 中先调用 `deployHelperScript()` 确保部署最新脚本，再执行命令。增加错误日志输出
