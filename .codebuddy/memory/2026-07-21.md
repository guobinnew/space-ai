# 2026-07-21

## 修复：任务清单组件（SessionTaskBar）闪烁
- 根因：服务端 `listTasks` 按 `updatedAt` 降序返回，agent 每更新一个任务其 `updatedAt` 就跳到最前，3s 轮询导致列表每轮重新排序 → 可见跳动/闪烁。之前的快照防重渲染（commit 84b3ac0）未覆盖此场景，因为顺序变化使快照 JSON 不同。
- 修复（`desktop/src/stores/cliTaskStore.tsx`）：前端接收任务后按 `id` 数值升序稳定排序再存状态/比对；并增加防御——同一会话内轮询返回空数组且此前有任务时跳过更新，避免瞬时空响应造成空白闪烁。
- commit 89e4ba7。

## 修复：任务清单执行完成后自动清空
- `cliTaskStore.tsx`：统一 `clearTasks(sessionId)` 删除服务端持久化数据 + 重置前端；移除只隐藏的 `dismissCompleted`。
- `ActiveSession.tsx`：轮询检测到无 pending/in_progress 且 agent idle 时自动 `clearTasks`；用 `chatStateRef` 读取最新状态避免闭包过期。
- `SessionTaskBar.tsx`：关闭按钮改为真正清空，接收 `sessionId`。
- commit 7e7454b。

## 修复：新会话自动生成 title 后 tab 页签不同步
- 根因：服务端 `sessionService.addUserMessage` 用首条消息前 30 字生成标题，但客户端 `uiStore.tabs` 与 `sessionStore.sessions` 从未同步。
- `uiStore` 新增 `updateTabTitle`；`chatStore.sendMessage` 首条消息后按相同规则同步标题到 tab 与侧边栏（`setSessions` 本地更新，避免多余请求）。`sessionStore` 暴露 `setSessions`。
- commit d051dee。

## 修复：agent 完成任务但 task 状态未更新
- 根因：agent 做完工作未调用 `TaskUpdate(completed)`，自动续跑 nudge 消息含糊（"Resume the in-progress task"）导致循环。
- `ActiveSession.tsx`：nudge 消息改为明确要求调用 `TaskUpdate` 标记 completed/in_progress。`prompts.ts`：强化系统提示词要求完成后必须标记。
- commit 9b7edb5。

## 修复：深度思考无限循环输出文字
- 根因：API 代理重发累积 thinking 文本，前端/服务端去重守卫用严格 `>` 无法匹配相同长度重发（停滞重发）→ 文本翻倍无限增长。
- `chatStore.tsx` 与 `llmStreamService.ts` 双端重写去重：累积重发(增长)、相同重发(停滞)、旧前缀重发三种模式 + 200000 字符安全阀。
- commit e243096。

## 修复：agent 说出意图后停止（不执行工具调用）
- 根因：agentic loop 用 `stopReason !== 'tool_use'` 判断是否继续，但代理不回传标准 stop_reason → 有 tool_use 也被丢弃。
- 改为只看 `toolUseBlocks.length === 0` 决定退出（与 smart-code 一致，其注释明确 stop_reason 不可靠）。
- commit 523932c。
