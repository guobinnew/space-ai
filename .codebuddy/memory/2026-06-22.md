## smart-space 项目初始化

- 创建了 smart-space monorepo 项目，npm workspaces 管理
- **desktop/**: Vite + React 18 + Tauri v2 桌面客户端
- **server/**: TypeScript + Node.js + Express 服务端，esbuild 打包为单文件 `dist/server.js`
- Tauri 打包时将 `server/dist/server.js` 作为 resource 嵌入
- `lib.rs` 在 `setup` 阶段以子进程方式启动 Node.js 服务，应用关闭时自动 kill
- 开发模式下 fallback 到 `../server/dist/server.js` 路径
- 服务端端口 3721，监听 127.0.0.1
- Cargo 镜像源从 tuna 切换到 rsproxy（tuna 不可达）
- 图标为脚本生成的占位 PNG，后续可用 `npx tauri icon` 替换
- Git 初始提交在 master 分支
- 添加 `tauri:dev` 命令：先构建服务端，再用 concurrently 并行启动服务端和 Tauri 客户端
- 修复：`tauri:dev` 添加 `--kill-others` 标志，关闭窗口时自动终止所有进程
- 重构子进程管理：Tauri 自动启动/停止 server 子进程，Windows 用 `taskkill /T /F` 杀进程树，`on_window_event` 监听窗口关闭
- `tauri:dev` 简化为只构建服务端 + 启动 Tauri（不再用 concurrently 单独启动服务端）
- 修复 dev 路径：`current_dir()` 在 dev 模式下是 `desktop/src-tauri`，需要 `.parent().parent()` 才能到项目根目录找到 `server/dist/server.js`
