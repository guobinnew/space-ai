## 修复 splash 窗口关闭误杀 server 的 bug

- 现象：应用启动后 server 进程立即被 kill（日志显示 Server started 后紧接 Killing server process）
- 根因：`lib.rs` 的 `on_window_event` 监听所有窗口的 `WindowEvent::Destroyed`，未区分窗口 label；前端 HomePage 延迟 500ms 调 `close_splashscreen` 关闭 splash 窗口 → 触发 Destroyed → 误执行 `state.kill()` 杀掉 server
- 修复：`on_window_event` 加 `window.label() == "main"` 判断，只在主窗口销毁时 kill server

## 修复 Windows 上 Command::new("bun") 找不到 bun 的问题

- 现象: tauri:dev 启动报 `Failed to start sidecar process: Error { kind: NotFound, message: "program not found" }`
- 根因: Windows 上 bun 通过 npm 安装为 shim(bun.cmd)，Rust 的 `Command::new("bun")` 底层用 CreateProcess，不解析 .cmd 扩展名
- 修复: dev 模式 Windows 上用 `cmd /C bun run sidecar.ts ...` 包装，cmd.exe 通过 PATHEXT 找到 bun.cmd；非 Windows 仍直接用 `bun`
