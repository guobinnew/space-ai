# SpaceAI Desktop 客户端使用手册

> 版本：v1.3.0 ｜ 更新日期：2026-08-03 ｜ 适用平台：Windows 10/11

SpaceAI Desktop 是基于 Tauri v2 + React 18 + TypeScript 构建的本地智能助手客户端。它把智能体对话、定时任务、文件浏览、代码编辑、TTS 朗读、技能市场等能力集成在单一桌面应用中，所有数据存于本地 `~/.spaceai/` 目录，注重隐私与可控性。

## 1. 安装与首次启动

### 安装

下载 `SpaceAI_x.y.x_x64-setup.exe` 后双击运行，按安装向导完成。默认安装到 `%LOCALAPPDATA%\Programs\SpaceAI\`。

### 首次启动注意事项

首次启动时，应用会拉起内置的本地服务端（端口 `3721`）。如果防火墙提示，请允许 `SpaceAI.exe` 与 `smart-sidecar.exe` 通过本地网络。

确认服务端就绪的方法：访问首页，左上角状态指示器应显示"**已连接**"（绿色）。如显示"**未连接**"：

1. 关闭应用，等待 5 秒后重启
2. 检查 3721 端口是否被其他进程占用
3. 如仍异常，删除 `~/.spaceai/sessions/index.json` 让其重建

### 配置目录

所有用户数据存放于 `~/.spaceai/`（即 `C:\Users\<用户名>\.spaceai\`）：

```
~/.spaceai/
├── sessions/            # 会话记录（目录结构，详见 §9）
├── settings.json        # 全局设置（主题/语言/默认工作目录/服务商 env 等）
├── providers.json       # 模型服务商配置
├── memory.db           # 智能体记忆数据库
└── logs/               # 应用与服务端日志
```

如需重置应用：退出后删除 `~/.spaceai/` 目录即可（**会清空全部会话与设置**）。

## 2. 主界面总览

应用采用三段式布局：

```
┌─────────────────────────────────────────────────────────┐
│  ☰  Tabs (首页 / 会话1 / 会话2 / 定时任务 / 设置)   ─ □ ✕ │  ← 顶栏 + 窗口控制
├──────────┬──────────────────────────────────────────────┤
│          │                                              │
│  Sidebar │              ContentRouter                   │
│  会话列表 │   （根据当前 Tab 渲染对应页面）             │
│  + 新建  │                                              │
│          │                                              │
└──────────┴──────────────────────────────────────────────┘
```

- **顶栏 Tab 栏**：多标签页切换，每个 Tab 对应一个会话或功能页。
- **侧边栏**：左侧会话列表，按"今天 / 昨天 / 本周 / 本月 / 更早"分组，右键支持重命名/删除。
- **内容区**：根据当前激活 Tab 显示对应页面。

侧边栏可折叠/展开（顶部 ☰ 按钮），会话列表每 15 秒自动刷新以同步定时任务新建的会话。

## 3. 侧边栏与会话管理

### 新建会话

点击侧边栏顶部"+"按钮（或快捷键 `Ctrl+N`）。新会话的"工作目录"默认为通用设置中的 `defaultWorkDir`。首次发送消息后，会话标题自动取首条用户消息前 30 字符。

### 切换会话

- 点击侧边栏会话条目即在新 Tab 打开
- 已打开的会话再点击则切到对应 Tab，不重复开

### 重命名

侧边栏条目右键 → **重命名**，输入新标题回车确认。

### 删除

侧边栏条目右键 → **删除**，确认后整个会话目录被移除（含消息、manifest、memory.md）。**不可恢复**。

### 工作目录

每个会话关联一个工作目录（agent 在该目录下读写文件）。在会话页面右上角点工作目录路径可修改。修改后该会话后续工具调用都会以新目录为根。

## 4. 会话页面（核心）

会话页面为左右双面板布局：

- **左侧**：聊天面板（消息列表 + 输入框 + 任务工具栏）
- **右侧**：文件浏览器面板（可隐藏，拖拽分隔条调整宽度，最小 400px）

分隔条可拖拽；双击分隔条可一键隐藏/展开右侧面板。

### 4.1 聊天面板

#### 输入消息

底部输入框支持多行（Shift+Enter 换行，Enter 发送）。输入框上方实时显示当前会话上下文使用量：

```
当前轮: 输入 12K · 输出 5K · 缓存读取 80K    累计: 输入 200K · 输出 50K
████████████░░░░░░░  67% / 200K
```

- **当前轮**：本轮 LLM 调用的 token 用量
- **累计**：本会话所有轮次累计
- **进度条**：当前消息占默认上下文窗口（200K）的比例

#### 模型服务商下拉

输入框右下方有服务商下拉框，列出所有已配置的服务商。**选择后立即生效**：下一次发送使用所选服务商。**正在进行的对话不受影响**（继续使用开始时的服务商）。

#### 流式输出

发送后立即进入流式响应：

- **思考块**：带折叠三角的灰色背景区块，显示扩展思考内容（仅 Anthropic 思考模型可见）
- **工具调用块**：每个工具调用单独显示，含工具名、输入参数、运行结果。结果可展开/折叠，可"复制为图片"
- **文本回复**：Markdown 渲染，支持代码块语法高亮、表格、列表、引用、链接
- **状态条**：底部状态条显示"思考中… / 流式输出中 / 空闲"

#### 停止生成

流式过程中输入框右侧"停止"按钮可中止当前生成。已生成的部分内容会保留。

#### 排队发送

生成中再次输入并按 Enter 会**排队等待**（不会打断当前生成）。排队中的查询依次执行，可在底部 QueryQueue 区域查看/重排/删除。

#### 复制消息

- **助手消息**：右下角"复制"按钮复制纯文本；"复制为图片"截图整条消息（含代码块、表格、思考块）
- **用户消息**：绿色气泡右下角"复制"按钮

#### 朗读（TTS）

在文件浏览器中打开 Markdown 文件后，阅读面板顶部有朗读按钮。需在"模型服务商"设置中配置 TTS 模型才能使用。

### 4.2 文件引用与代码引用

在输入框中可通过以下方式插入文件/代码/目录引用（agent 收到的消息会带引用标记）：

#### 拖拽插入

- 拖拽文件到输入框 → 插入 `[File: <路径>]` 标签，agent 读取该文件内容
- 拖拽目录到输入框 → 插入 `[Directory: <路径>]` 标签
- 拖拽代码文件并选中行范围 → 插入 `[File: <路径> (L<起>-L<止>)]` 代码引用

#### 输入框内的标签

引用标签以彩色卡片形式显示在输入框上方，每个标签含文件名和路径。可点击 ✕ 删除。

#### 历史消息中的引用

历史消息中显示的引用标签会**异步检查源文件是否存在**：

- 文件存在 → 标签可点击，点击后在右侧编辑器打开对应文件
- 文件已被删除/移动 → 标签变为红色边框 + 三角警告图标 + 透明度降低，**禁用点击**

> 这避免了"点击引用却 404"的困惑。tooltip 显示完整路径或"路径不存在"提示。

### 4.3 会话消息查找

会话页面顶部工具栏右侧有"查找"按钮（放大镜图标）。点击进入查找模式：

- **顶部**：关键词输入框 + 大小写敏感 / 全字匹配 / 正则表达式 三个开关
- **下方**：搜索结果列表，每条结果高亮匹配文本
- **点击结果**：退出查找模式，自动滚动到对应消息位置

查找模式覆盖整个底部区域（输入框、排队区、任务栏均被遮罩）。退出查找时**保留当前搜索状态**（关键词、开关），下次进入延续上次设置。

### 4.4 文件浏览器与编辑器

右侧文件浏览器面板按会话工作目录为根。支持：

- **目录树**：层级展开/折叠，点击文件在编辑器中打开
- **代码编辑器**：基于 Monaco，支持语法高亮、行号、基础编辑
- **预览组件**：
  - 图片：`.jpg / .png / .gif / .webp`
  - Excel：`.xlsx`（表格预览）
  - Word：`.docx`（文档预览）
  - PowerPoint：`.pptx`（幻灯片预览）
  - Markdown：渲染后预览 + 朗读
- **代码引用**：编辑器中选中行范围 → 上下文菜单"复制为代码引用" → 粘贴到聊天输入框即生成代码引用标签

### 4.5 任务清单工具栏

会话页面顶部状态条会显示"未完成任务"提示。当 agent 创建任务清单（TaskList）时：

- **进入会话**：若有未完成任务，弹窗询问"是否继续执行？"
- **自动续跑**：agent 空闲但有 pending/in_progress 任务时自动续跑
- **手动控制**：底部 SessionTaskBar 显示当前任务列表，可勾选完成/删除任务
- **完成清理**：全部任务完成且 agent 空闲时自动清空任务清单

### 4.6 排队查询

底部 QueryQueue 显示等待中的查询卡片：

- 拖拽卡片调整顺序
- 点击 ✕ 删除单个查询
- 当前生成完成后自动执行下一个

## 5. 首页（Dashboard）

首页是应用打开后第一个 Tab，提供全局概览：

- **服务状态**：左上角连接状态指示器
- **今日统计**：今日累计 input/output/cacheRead token 数（按服务商分组）
- **定时任务摘要**：近期定时任务列表 + 最近 5 次运行记录
- **最近会话**：最近 5 个会话快速入口

点击任一卡片可跳转到对应详情页（定时任务页 / 会话页 / 使用统计页）。

首页每 15 秒自动刷新会话列表，定时任务状态实时刷新（无需切页）。

## 6. 定时任务

定时任务页（侧边栏"定时任务"图标或首页卡片入口）：

### 任务列表

- 显示所有已创建的定时任务，含名称、Cron 表达式描述、最近运行时间、状态
- 状态颜色：**绿色**=最近成功 / **红色**=最近失败 / **灰色**=暂停 / **蓝色**=运行中

### 创建任务

点击"新建任务"按钮：

- **名称**：任务显示名
- **Cron 表达式**：支持标准 5 段格式（分 时 日 月 周）。下方实时显示人类可读描述（如"每天 09:00"）
- **查询内容**：任务执行时发送给 agent 的指令
- **目标工作目录**：可选，agent 在该目录下执行
- **目标智能体**：可选，使用自定义智能体执行

### 管理

- 暂停/恢复：点击任务条目右侧暂停按钮
- 立即执行：强制触发一次（不影响下次定时）
- 删除：移除任务（不会撤销已生成的会话）

### Cron 表达式速查

| 表达式 | 含义 |
|---|---|
| `0 * * * *` | 每小时整点 |
| `*/30 * * * *` | 每 30 分钟 |
| `0 9 * * *` | 每天 09:00 |
| `0 9 * * 1-5` | 工作日 09:00 |
| `0 0 1 * *` | 每月 1 号 00:00 |
| `0 9,18 * * *` | 每天 09:00 与 18:00 |

使用统计页（侧边栏"统计"图标）：

数据来自服务端 `usage.jsonl`（位于 `~/.spaceai/`），仅记录有服务商字段的调用，第三方 API 兼容模式下的调用也会被记录。

## 8. 设置

设置页（侧边栏齿轮图标）左侧分类导航，右侧设置项。

### 8.1 通用设置

| 项 | 说明 |
|---|---|
| 主题 | 浅色 / 深色（默认深色）。所有界面同步切换 |
| 语言 | 中文 / English（默认中文）。切换后立即生效 |
| 默认工作目录 | 新建会话默认的工作目录 |
| 完成通知 | agent 完成任务后是否显示系统通知 |
| 联网搜索 | 启用后 agent 可调用网络搜索，需选服务商并填 API Key |

所有通用设置持久化到服务端 `~/.spaceai/settings.json`，跨设备同步需手动复制该文件。

### 8.2 模型服务商

服务商配置管理 LLM 调用凭证与端点：

- **服务商列表**：每个服务商卡片显示名称、API 格式（Anthropic / OpenAI 兼容）、模型、是否默认
- **添加服务商**：选 API 格式 → 填名称、API Key、Base URL（可选）、模型名
- **设置默认**：点击"设为默认"按钮，新会话默认使用该服务商
- **TTS 配置**：每个服务商可单独配置 TTS 模型（用于朗读功能）
- **环境变量**：API Key 等敏感字段加密存于 `settings.json` 的 `env` 字段

> **第三方 API 兼容**：DeepSeek / Qwen / Moonshot / MiniMax / GLM 等使用 OpenAI 兼容格式，选 "OpenAI 兼容" 并填对应 Base URL 即可。

### 8.3 技能管理

技能是可插拔的能力扩展包，提供领域知识、SOP 流程、可执行脚本：

- **列表视图**：顶部统计卡片（已安装/总数）+ 技能列表（名称、描述、来源）
- **详情视图**：点击技能进入，显示元信息 + 文件树 + 文件预览
- **文件树**：层级展开，点击文件在右侧 CodeViewer 中预览（支持语法高亮）
- **返回**：详情视图左上角"返回"按钮回到列表

技能来源：内置（随应用打包）+ 自定义（用户在 `~/.spaceai/skills/` 下放置）。

### 8.4 计算机操作

授权应用管理与环境检测：

- **环境检测**：显示本机授权环境是否就绪
- **授权应用**：列出已授权可被 agent 控制的应用
- **Grant Flags**：精细控制 agent 可执行的敏感操作（写文件、执行命令、网络请求等）

### 8.5 记忆管理

跨会话持久记忆：

- **条目列表**：每条记忆含标题、内容、创建时间、关联会话
- **新增/编辑/删除**：手动维护
- **统计**：显示总条目数、最近使用情况

记忆数据库位于 `~/.spaceai/memory.db`（SQLite）。agent 在对话中可主动写入与查询记忆。

### 8.6 智能体管理

内置 + 自定义智能体：

- **内置**：默认 agent，不可删除
- **自定义**：创建时填名称、描述、系统提示词、关联技能、默认工作目录
- **编辑/删除**：自定义智能体可编辑或删除
- **使用**：在新建会话或定时任务时选目标智能体

### 8.7 关于

显示应用版本号、构建时间、Git commit hash、技术栈信息。

## 9. 数据存储与会话压缩

### 会话存储结构

每个会话独立目录：`~/.spaceai/sessions/<sessionId>/`

```
~/.spaceai/sessions/session-1785212002828-oh32yl/
├── manifest.json               # 元信息
├── memory.md                   # 压缩摘要（可选）
├── 2026-07-28.jsonl            # 按天分文件
├── 2026-07-29.jsonl
└── 2026-08-03.jsonl
```

**`manifest.json`** 字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `sessionId` | string | 会话唯一 ID |
| `title` | string | 会话标题 |
| `workDir` | string? | 工作目录 |
| `channel` | string | 来源（desktop/cron） |
| `createdAt` | ISO | 创建时间 |
| `modifiedAt` | ISO | 最后修改时间 |
| `messageCount` | number | 消息总数 |
| `compactedThroughDate` | string? | 压缩截止日（YYYY-MM-DD），null 表示未压缩 |

### 按天分页加载

前端默认只加载最新一天的消息。向上滚动到接近顶部时自动加载前一天的 jsonl 并 prepend 到消息列表，保持视觉位置不跳动。压缩截止日之前的 jsonl 不直接展示，其内容已合并到 `memory.md`。

### 上下文压缩（auto-compact）

**触发条件**：当累计消息 token 估算（chars / 4）超过 `contextWindow - 20000 - 13000` 时触发。Anthropic 默认 200K，OpenAI 默认 128K。

**压缩流程**（按天粒度）：

1. 取 `compactedThroughDate` 之后所有按天 jsonl 文件
2. 选定"待压缩截止日" = 这些天里除最新一天外的最大日（保留最新一天不压缩）
3. 把 `[旧 compactedThroughDate+1, 待压缩截止日]` 范围的所有消息送 LLM 生成摘要
4. 若已有旧 `memory.md`：旧摘要 + 新增内容 → 再次 LLM 总结 → 合并更新
5. 写回 `memory.md` + 更新 `manifest.compactedThroughDate`
6. **原始 jsonl 文件保留不删除**

**上下文拼装**（LLM 调用时）：

1. 若 `memory.md` 存在 → 作为开头一条 user summary 消息（"以下是此前对话的压缩摘要…"）
2. 加载 `compactedThroughDate` 之后所有 jsonl 的消息
3. 当前用户消息追加在末尾

> 这种设计既控制了 token 用量，又保留了原始数据可追溯性。`memory.md` 是 LLM 总结，可能与原文有出入，关键决策应回查原始 jsonl。

### 旧格式兼容

首次访问旧 `<id>.jsonl` 单文件时自动迁移：按 timestamp 本地日期切分到对应 jsonl，写 manifest，删除原文件。一次性批迁移可运行：

```bash
bun run scripts/migrate-sessions.ts
```

## 10. 常见问题

### Q1：启动后首页显示"未连接"

1. 退出应用，5 秒后重启（让 sidecar 进程清理）
2. 检查 3721 端口占用：`netstat -ano | findstr :3721`
3. 删除 `~/.spaceai/sessions/index.json` 让其重建
4. 查看 `~/.spaceai/logs/` 下最新日志

### Q2：消息发送后无响应

1. 检查模型服务商是否已设默认（设置 → 模型服务商 → 设为默认）
2. 检查 API Key 是否有效
3. 查看会话页面底部状态条是否显示"思考中"，若显示则是在等待首 token
4. 第三方 API 偶发超时可重试

### Q3：TTS 朗读提示"未配置 TTS"

设置 → 模型服务商 → 编辑当前默认服务商 → 配置 TTS 模型字段。Anthropic 用 `claude-3-sonnet` 等；OpenAI 用 `tts-1` / `tts-1-hd`。

### Q4：文件引用标签变红 disabled

源文件已被删除或移动。tooltip 显示完整路径。可：

- 在文件管理器中找回该文件放回原路径
- 或忽略该引用，重新拖拽新文件到输入框

### Q5：定时任务不执行

1. 检查任务状态是否为"暂停"
2. 查看 `~/.spaceai/logs/` 下 cron 调度日志
3. Cron 表达式语法错误会导致任务被跳过，创建时下方的人类可读描述若不正确即说明语法错
4. 确认应用在运行（关闭应用后定时任务不执行）

### Q6：会话列表中显示了已删除的会话

`index.json` 与实际目录可能短暂不一致。手动刷新：切换侧边栏到其他 Tab 再切回，或重启应用。

### Q7：上下文压缩后 agent 行为异常

`memory.md` 是 LLM 总结，可能丢失关键细节。如发现 agent 在压缩后忘记重要上下文：

1. 在会话目录下查看对应日期的原始 jsonl 文件
2. 把关键信息重新在对话中告诉 agent
3. 或删除 `memory.md` + 重置 `manifest.compactedThroughDate = null`（让所有原始消息重新进入上下文，但可能超 token 限制）

### Q8：如何完全重置应用

退出应用后删除整个 `~/.spaceai/` 目录即可。下次启动会重新创建空目录，所有会话、设置、技能配置全部清空。
